# MNotch 1.5.2

## English

- Volume and brightness HUDs expand sideways while keeping the closed notch's height. The lower edge now fills the visible menu-bar band, including the extra 1 pt on affected displays, with the contrast outline contained inside it.
- HUDs can appear temporarily over full-screen apps while the normal notch stays hidden. Mission Control and gaming suppression still apply; full-screen HUDs pass pointer input through.
- Add an option to hide the simulated notch until the pointer reaches it, and refresh the application and menu-bar icons.
- Improve thumbnail cleanup, service shutdown, bounded file reads and background rendering to reduce unnecessary memory and CPU work.
- Restore brightness controls on the verified Mac17,3 / macOS 27.0.1 (26A434) combination. Hardware calls run on a dedicated serial queue, repeated steps coalesce, and unavailable or stalled controls return keys to macOS. Other unverified private integrations remain disabled.

Requires macOS 15 or later. Brightness compatibility is limited to the verified configuration above; this release does not certify every Mac and macOS combination.

## Tiếng Việt

- HUD âm lượng và độ sáng chỉ nở ngang, giữ nguyên chiều cao notch đóng. Sửa khe hở 1 pt dưới hàng menu và giữ viền tương phản nằm trong mép notch.
- HUD vẫn hiện tạm trong ứng dụng toàn màn hình; notch thường tiếp tục ẩn. HUD toàn màn hình cho chuột đi xuyên qua, vẫn ẩn khi mở Mission Control hoặc bật chế độ game.
- Thêm tự ẩn notch giả đến khi đưa chuột vào, cập nhật icon ứng dụng và menubar.
- Giảm công việc render nền, kiểm soát vòng đời thumbnail, dịch vụ và đọc file để tăng độ ổn định.
- Bật lại độ sáng trên tổ hợp đã kiểm chứng Mac17,3 / macOS 27.0.1 (26A434). Đọc/ghi phần cứng chạy trên hàng đợi riêng, gộp lệnh liên tiếp và trả phím về macOS khi dịch vụ lỗi hoặc không phản hồi. Các tích hợp riêng tư chưa được kiểm chứng vẫn tắt.

Yêu cầu macOS 15 trở lên. Hỗ trợ độ sáng hiện giới hạn ở tổ hợp đã kiểm chứng nêu trên.
