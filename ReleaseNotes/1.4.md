# MNotch 1.4

## English

- Adds signed automatic updates powered by Sparkle 2.9.4.
- Checks for updates daily, with optional automatic download and install on quit.
- Adds “Check for Updates…” to the menu-bar menu and Settings → About.
- Verifies the signed appcast and update archive before extraction.

## Tiếng Việt

- Bổ sung cập nhật tự động có chữ ký bằng Sparkle 2.9.4.
- Kiểm tra bản cập nhật hằng ngày, kèm tùy chọn tự tải và cài khi thoát ứng dụng.
- Thêm “Kiểm tra bản cập nhật…” vào menu thanh trạng thái và Cài đặt → Giới thiệu.
- Xác thực appcast và gói cập nhật có chữ ký trước khi giải nén.
