# MNotch 1.5.4

## English

- Recognize the Codex CLI bundled in current Codex app releases, including apps moved or renamed on disk. Existing CLI installations and custom paths continue to work.
- Show Claude subscription usage for the current session and week instead of token/cost statistics. Quota keeps updating when Claude Code and Claude Desktop are closed, using the existing saved sign-in.
- To connect Claude Desktop, open **Settings → AI Agent → Claude usage → Connect Claude**. If macOS asks for access to **Claude Safe Storage**, choose **Always Allow** to keep the connection after restarting MNotch. If the saved sign-in expires or is revoked, sign in to Claude again and reconnect.

MNotch reads usage without refreshing shared tokens or changing Claude's files. Requires macOS 15 or later on Apple Silicon.

## Tiếng Việt

- Nhận diện CLI Codex được tích hợp trong các bản Codex mới, kể cả khi ứng dụng đã được di chuyển hoặc đổi tên. Các bản CLI cài riêng và đường dẫn tùy chỉnh vẫn được hỗ trợ.
- Hiển thị đúng hạn mức thuê bao Claude theo phiên và tuần, thay cho thống kê token/chi phí. Hạn mức tiếp tục cập nhật khi đã đóng cả Claude Code và Claude Desktop, sử dụng đăng nhập đã lưu.
- Để kết nối Claude Desktop, mở **Cài đặt → AI Agent → Mức sử dụng Claude → Kết nối Claude**. Nếu macOS hỏi quyền truy cập **Claude Safe Storage**, chọn **Luôn cho phép** để giữ kết nối sau khi khởi động lại MNotch. Nếu đăng nhập đã lưu hết hạn hoặc bị thu hồi, hãy đăng nhập lại Claude rồi kết nối lại.

MNotch đọc hạn mức mà không làm mới token dùng chung hoặc sửa file của Claude. Yêu cầu macOS 15 trở lên và Apple Silicon.
